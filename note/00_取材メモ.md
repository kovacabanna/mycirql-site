# 取材メモ（音声入力の書き起こし・整理版）

> 音声入力の崩れを直しただけの記録です。記事に使わなかった要素も残してあります。

## 作ったきっかけ

- **昨年、父が亡くなった。**80歳になる手前だった。
- 父のいとこ、兄弟も当然その年代。葬儀に来てくださった。
- **父と自分は顔がとても似ている。**誰がどう見ても父の子だとわかる。
  → 来てくれた人からは「こいつが息子だ」と一目瞭然だったはず。
- **しかし自分からは、その人が誰なのかわからなかった。**
  - 親族なのか、友人なのか
  - 親族だとして、いとこなのか
  - 誰の、どういう関係の人なのか
- わからないまま挨拶するので、**当たり障りのない会話にしかならない。**

## 田舎あるある：呼び名が地域名

- 「どこどこのおじちゃん」「どこどこのおばちゃん」「横浜のおばちゃん」
- **地域名＋続柄**が、その人の呼び名として通っている
- 「林田兄ちゃん」のように**苗字＋続柄**ならまだいい（あとで照合できる）
- 地域名＋おじいちゃん、で通っている人が思ったより多い

## 詰まったところ：香典返しの住所リスト

- 香典をいただいた以上、香典返しをしないといけない
- 葬儀が終わってひと段落した最後のほうで、**葬儀屋に香典返しの住所リストを作って渡す**必要がある
- ここで詰まった

### 「わからない」の4種類

1. そもそも名前を知らない
2. 顔は知っているが、名前を知らない
3. 名前は知っているが、顔と一致しない
4. 名前も顔も知っているが、**どういう血縁関係かわからない**

## 解決した方法

- 葬儀が一段落したあと、**いとこの中でも親しい人間と、手書きで家系図を作って整理した**
- → これがアプリを作ろうと思ったきっかけ

## 記事に効く点（編集メモ）

- 「顔は似ているのに、相手のことは何もわからない」という**非対称**が、この話のいちばん強いところ
- 「わからない」の4分類は、そのまま図にできる（記事の図1に採用）
- 香典返しリスト → アプリの **CSV／PDF書き出し** に直結する
- 手書きの家系図 → アプリの **家系図自動生成** に直結する
- 「次に必要になるのは、また誰かが亡くなったとき」→ **命日通知（四十九日〜三回忌）**の動機になる
