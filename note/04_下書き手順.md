# note 下書き作成の手順

`03_下書き用_コピペ本文.md` を使って、5分ほどで下書きが完成します。

## 手順

1. note で「投稿する」→「テキスト」を選び、新規記事を開く
2. **タイトル欄**に、`03_下書き用_コピペ本文.md` の1行目（見出しの一文）を貼る
   > 顔は知られているのに、私は誰なのか分からなかった。父の葬儀で作ったアプリの話
3. **本文欄**に、2行目以降を上から順に貼っていく
   - `##` の行は note 側で自動的に見出しになる場合と、ならない場合があります。
     ならなかった場合は、その行を選択して、ツールバーの「見出し」ボタンを押してください
   - `**〜**` も同様に、貼った直後に太字になっていなければ、選択してツールバーの「B」を押してください
4. **`▼［ここに fig◯.png（〜）を挿入］`** という行が6か所あります。
   その行に来たら、
   1. まずその行の文字を削除
   2. note のツールバーの画像アイコンから、`note/img/fig◯.png` をアップロード
   （番号は本文中に書いてある通りです。fig1→fig6の順に出てきます）
5. 最後まで貼り終えたら、記事の一番下に **アイキャッチ画像** を設定
   - おすすめは `fig2.png`（アプリの全体像）。図2が最も「一枚で内容が伝わる」図のためです
6. **ハッシュタグ**を設定（note の投稿画面下部、タグ入力欄）
   ```
   #個人開発 #アプリ開発 #iOSアプリ #家系図 #エッセイ
   ```
7. 画面右上などにある **「保存」または「下書き保存」** を押す（公開ボタンは押さない）

これで下書きが完成します。公開はご自身のタイミングで行ってください。

## 貼り付け後に必ず確認してほしいこと

- 見出し（`##` だった行）が、本文と同じ大きさのまま埋もれていないか
- 太字（`**`だった箇所）が反映されているか
- 6箇所の画像が、それぞれ対応する本文の直後に入っているか（fig1〜fig6の順）
- 最後の App Store リンクが、リンクとして機能しているか（note は URL を貼ると自動でリンク化することが多いですが、念のため）

## もし note がインポート機能を持っている場合

note の投稿画面に「Markdownインポート」や「テキストファイルの読み込み」のような機能があれば、
`03_下書き用_コピペ本文.md` をそのまま読み込ませても構いません。その場合も、画像6箇所の手動アップロードだけは必要です。
